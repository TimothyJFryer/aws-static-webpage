Static Website on AWS

A simple static website hosted on Amazon S3 with CloudFront distribution

About This Project

This is just a basic website to show my ability to use AWS. I have focused on purely AWS and not the website design itself.

What I Built

  • Step 1 - Build this website (For Transparency this was assisted by online website templates and AI tools, as I want to display AWS skills not frontend design skills)
  • Step 2 - Set up S3 bucket. The required settings included Static website hosting on, Block all public access and Bucket policy to allow CloudFront access.
  • Step 3 - Set up CloudFront. This give much lower latency, and ensures users may only access the website through CloudFront and not the s3 directly
  • Step 3 - Upload these website files (Using CLI)
