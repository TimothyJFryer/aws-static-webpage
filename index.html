Static Website on AWS

A simple static website hosted on Amazon S3 with a CloudFront distribution

About This Project

This project demonstrates my ability to use AWS services to design, deploy, and deliver a static website using Amazon S3 and CloudFront, with a focus on cloud infrastructure rather than frontend design.

What I Built

  • Step 1 - Built this website. (For transparency, this was assisted by online templates and AI tools, as the focus is on demonstrating AWS skills rather than frontend design.)
  • Step 2 - Set up an S3 bucket. Required settings included enabling static website hosting, configuring public access settings appropriately, and applying a bucket policy to allow CloudFront access.
  • Step 3 - Set up CloudFront. This improves performance through caching at edge locations and ensures users access the website via CloudFront rather than directly through S3.
  • Step 4 - Uploaded website files using the AWS CLI.

Architecture

User → CloudFront → S3 Bucket → Website Files

Users access the CloudFront domain, which serves cached content from the S3 bucket, reducing latency and improving global performance.

AWS Services Used

Amazon S3 CloudFront

  • Static website hosting
  • Content delivery network (CDN) concepts
